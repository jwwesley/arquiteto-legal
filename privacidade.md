# Politica de Privacidade do Arquiteto

O Arquiteto e um aplicativo pessoal, usado apenas pelo proprio desenvolvedor. Esta politica explica quais dados ele acessa.

## Dados acessados

Com a autorizacao do proprio usuario, o aplicativo acessa a conta Google para: ler e escrever tarefas no Google Tarefas; e ler e gravar arquivos criados pelo proprio aplicativo no Google Drive.

## Como os dados sao usados

Os dados sao usados somente para organizar a rotina e as tarefas do usuario. Ficam guardados no computador do usuario e na propria conta Google dele.

## Compartilhamento

Nenhum dado e vendido, compartilhado ou transferido a terceiros. O uso das informacoes recebidas das APIs do Google segue a Politica de Dados de Usuario dos Servicos de API do Google, incluindo os requisitos de Uso Limitado.

## Remocao de acesso

O usuario pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.
